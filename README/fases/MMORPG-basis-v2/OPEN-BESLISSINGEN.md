# Open beslissingen voor Kevin

**Gebruik:** dit zijn gates voor latere uitvoering, geen vragen die dit masterplan ophouden. Alle defaults hieronder zijn **AANNAME**, tenzij het besluit expliciet al in `README/PROJECT_CONTRACT.md` of de code staat. Kevin bevestigt of wijzigt ze bij het genoemde moment. Een AI-agent mag een open besluit niet stilzwijgend als definitief productbeleid coderen. `NO-GO` betekent: die fase niet afronden of externe testers niet uitnodigen.
